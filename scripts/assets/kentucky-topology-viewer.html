What the connection policy would mean here

An undersized disconnected component can attach to the main source component through one explicit, recorded connection. With only one district-sized root, population-aware grouping does not need to merge competing large islands.

A district can use that connection only if it owns both endpoint blocks. Its assigned polygon parts must connect through shared edges and its own recorded links; it cannot borrow a different district’s route.

What remains to be demonstrated

The proposed link tests source connectivity and removes the component-total population obstruction. A complete benchmark must still solve each plan, repair and rebalance whole blocks, and independently validate its final polygons and same-district link endpoints.

The strict results remain preserved as strict exceptions. A map accepted under a recorded connection policy would be described as policy-connected; the detached geography would remain physically separate.
