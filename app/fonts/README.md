# Bundled fonts

The WOFF2 files come from the variable TrueType fonts in the `inter`, `jetbrainsmono`, `instrumentsans`, and `newsreader` directories of this [Google Fonts revision](https://github.com/google/fonts/tree/cc5661d43cd4f9aad5567033a8e15ca28dc35c86/ofl). Each family’s license is included alongside its font files.

The files retain the full glyph sets. During WOFF2 conversion with FontTools, Inter’s optical size was fixed at 14 and Instrument Sans’s width at 100 to match the original styles. Both Newsreader faces retain variable optical sizing.
