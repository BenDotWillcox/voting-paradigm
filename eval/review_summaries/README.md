# Participant-Safe Review Summaries

This directory contains only summaries generated by
`python -m eval.validate_batch_review`. The schema allowlists aggregate hashes,
reviewer provenance, approval status, and finding counts. It excludes packet,
option, source, assumption, finding, and disposition prose.

Exact batches and detailed review logs remain under the Git-ignored
`eval/restricted_bank/` directory until the blinded evaluation and retest are
complete. Do not manually author or paraphrase a summary into this directory.
