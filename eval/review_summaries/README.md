# Participant-Safe Review Summaries

This directory contains only summaries generated by the aggregate-safe review
validators: `python -m eval.validate_batch_review`,
`python -m eval.validate_retest_review`, and
`python -m eval.validate_phase4_semantic_review`. Their schemas allowlist
artifact hashes, reviewer provenance, approval status, and aggregate finding
counts. They exclude packet, option, source, assumption, mapping, rationale,
finding, and disposition prose.

Exact batches and detailed review logs remain under the Git-ignored
`eval/restricted_bank/` directory until the blinded evaluation and retest are
complete. Do not manually author or paraphrase a summary into this directory.
